  2. Vehicle Listing — Year/make/model/miles/condition + “Add to Bids”.
  3. Bidding Column — Active vehicles with firm offers pending inspection.
  4. Geolocation — Owner location for relevance; dealers at any distance.
  5. Notifications — New bids, offer accepted, inspection ready.
  6. Tech Stack — Supabase (auth + Postgres + realtime) or Firebase; Vercel/Hostinger hosting; optional VIN decode.
